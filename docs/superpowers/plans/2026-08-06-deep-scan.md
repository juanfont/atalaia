# Deep Scan Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an opt-in second LLM pass that reads a diff's added lines cold, grounds every candidate credential against the diff itself, and reports what no detector flagged in a separate `discoveries[]` channel.

**Architecture:** `POST /check` gains a `deep` flag. When set, a `DeepReader` packs the diff's added-line blocks into budget-sized windows, asks the LLM for candidate credentials (verbatim values, no locations), and a pure `Ground` function locates each value in the diff with `detector.LocateInDiff`, discarding anything it cannot find. Grounded discoveries land in `discoveries[]`, never in `verdicts[]`. The detector pipeline and adjudication are untouched.

**Tech Stack:** Go 1.22+, `text/template` prompts, OpenAI-compatible chat completions with tool calling, Prometheus metrics, gorilla/mux, zerolog, Viper config.

**Spec:** [docs/superpowers/specs/2026-08-05-deep-scan-design.md](../specs/2026-08-05-deep-scan-design.md)

## Global Constraints

- **Never import trufflehog as a Go module.** It is AGPL-3.0 and runs as a subprocess only. Atalaia is BSD-3-Clause.
- **No raw matches in API responses or non-audit logs, ever.** Responses carry `match_preview` only. Raw values reach the audit log only when `observability.audit.reveal_matches` is true.
- **Statelessness:** no on-disk state for diffs, findings, verdicts, or discoveries.
- **No new outbound network calls.** The only egress remains atalaia → its configured LLM endpoint.
- **Verdict and discovery correlation is by id, never by array position.**
- **Default path must be bit-for-bit unchanged.** A request without `deep` must produce the same response bytes as before this feature, and must make no deep LLM call.
- **Writing style for all comments and docs:** direct, economical, short sentences. No hedging, no filler. Em/en dashes get cut, replaced by periods or commas.
- Verify with `go build ./... && go vet ./... && gofmt -l . && go test ./...` before every commit.
- Existing id scheme is `sha256(file + ":" + line + ":" + match)[:12]` via `detector.FindingID`. Reuse it, do not invent a second one.

- [ ] **Step 1: Write the system template**

Create `prompts/gemma4_deep_system.tmpl`. This is deliberately NOT the adjudication prompt's posture. That one is a default-dismiss precision filter handed a candidate; this one is recall over a haystack with nothing handed to it.

```
You are a secret-scanning reader. You receive added lines from a git
diff. Regex scanners have already run and missed things; your job is to
find live credentials and private key material they did not catch.

Report a value only if it is a literal credential sitting in the diff:
an API key, token, password, or connection string with a real password
in it, or private key material (PEM blocks, SSH private keys).

Do NOT report:
- References. A $VAR, ${VAR}, environment or CI variable, config lookup,
  attribute access, function call, or bare identifier is not a secret.
  The value is supplied at runtime and is not in the diff.
- Placeholders and examples: <your-key>, changeme, AKIAIOSFODNN7EXAMPLE,
  ya29.dummy, sk-test-..., and anything the surrounding code or comments
  present as fake, sample, or illustrative.
- Hashes, checksums, UUIDs, commit SHAs, base64-encoded data that is not
  a credential, and high-entropy strings with no credential role.

For every value you report, copy it VERBATIM, exactly as it appears in
the line, byte for byte. Do not paraphrase, truncate, reformat, or strip
quotes. A value that does not appear in the diff exactly as you wrote it
is discarded.

For private key material, return the BEGIN header line, not the key body.

Most diffs contain nothing. Returning an empty list is the correct and
common answer.

Return a JSON object matching the response schema.
```

- [ ] **Step 4: Score two rates by hand**

For each returned candidate, check whether the value appears verbatim in the diff:

```bash
grep -F -- '<the returned value>' <the diff> && echo GROUNDED || echo HALLUCINATED
```

Record:
- **Hallucination rate** = hallucinated candidates ÷ total candidates. This is what `Ground` will silently discard, so a high rate is survivable but wasteful.
- **False alarm rate** = clean diffs producing at least one grounded candidate ÷ clean diffs. This is the one that decides the feature. A clean diff yielding confident credentials means the quiet fixture in Task 9 cannot pass.

- [ ] **Step 5: Decide, and record the decision**

- False alarm rate near zero: proceed with the plan as written.
- False alarm rate high: the architecture does not change, its default does. Scope the deep read to diffs that already carry detector findings, which shrinks the haystack to the originally reported case. Implement that by returning early from `DeepReader.Scan` when `len(deduped) == 0`, and add `deep_scan.require_findings: true` to the config in Task 2.

Append the measured numbers and the decision to the spec under a new `## Step zero results` heading, so the next reader knows what the prompt was actually tested against.

```go
package llm

import (
	"strings"

	"github.com/juanfont/atalaia/internal/detector"
)

// deepWindowHeader prefixes each block with its file so the model can
// name what it is reading. Line numbers are deliberately absent: the
// model never supplies a location, grounding derives it from the diff.
const deepWindowHeader = "=== "

// buildDeepWindows renders the diff's added lines into budget-sized
// windows for the deep read.
//
// Only added lines are scanned. Context and removed lines are dropped:
// a secret that appears only in a removed line was committed in an
// earlier push and belongs to a history scan, not this one. Dropping
// them is also what makes the deep read affordable, since the added-line
// set is a fraction of a typical diff.
//
// Windows are capped at maxWindows. When blocks remain past the cap,
// truncated is true and the caller reports incomplete coverage.
func buildDeepWindows(diff []byte, inputBudget, outputBudget, maxWindows int) ([]string, bool) {
	budget := inputBudget - outputBudget
	if budget < 256 {
		budget = 256
	}

	var (
		windows []string
		cur     strings.Builder
		curTok  int
	)
	flush := func() {
		if cur.Len() > 0 {
			windows = append(windows, cur.String())
			cur.Reset()
			curTok = 0
		}
	}

	for _, block := range detector.WalkDiff(diff) {
		for _, chunk := range splitBlock(block, budget) {
			t := estimateTokens(chunk)
			if curTok > 0 && curTok+t > budget {
				flush()
			}
			cur.WriteString(chunk)
			curTok += t
		}
	}
	flush()

	if maxWindows > 0 && len(windows) > maxWindows {
		return windows[:maxWindows], true
	}
	return windows, false
}

// splitBlock renders one AddedBlock as header plus body, splitting it
// by lines when the block alone exceeds one window's budget. Every
// piece repeats the header so no window is anonymous.
func splitBlock(block detector.AddedBlock, budget int) []string {
	header := deepWindowHeader + block.Path + "\n"
	whole := header + block.Content + "\n"
	if estimateTokens(whole) <= budget {
		return []string{whole}
	}

	var (
		out  []string
		cur  strings.Builder
		tok  int
		head = estimateTokens(header)
	)
	cur.WriteString(header)
	tok = head

	for _, line := range strings.Split(block.Content, "\n") {
		lt := estimateTokens(line) + 1
		if tok > head && tok+lt > budget {
			out = append(out, cur.String())
			cur.Reset()
			cur.WriteString(header)
			tok = head
		}
		cur.WriteString(line)
		cur.WriteString("\n")
		tok += lt
	}
	if tok > head {
		out = append(out, cur.String())
	}
	return out
}

```go
package llm

import (
	"strings"

	"github.com/juanfont/atalaia/internal/detector"
	"github.com/juanfont/atalaia/internal/metrics"
	"github.com/juanfont/atalaia/internal/redact"
)

// minCandidateChars rejects values too short to be a credential. Below
// this the substring search matches half the diff.
const minCandidateChars = 6

// DeepCandidate is one claim from the deep read, before grounding. The
// model supplies no file, no line, and no id: it has no way to express
// a location, so it has no way to hallucinate one.
type DeepCandidate struct {
	Value      string
	Kind       string
	Confidence float64
	Reason     string
}

// Discovery is a grounded candidate: a value the model claimed and the
// diff confirmed, with a position derived from the diff itself.
//
// Match holds the raw value for the audit path only. It must never
// reach an API response or a non-audit log; callers copy MatchPreview.
type Discovery struct {
	ID           string
	File         string
	Line         int
	Match        string
	MatchPreview string
	Kind         string
	Confidence   float64
	Reason       string
}

// GroundStats is the per-request accounting the API layer reports.
type GroundStats struct {
	Candidates int
	Discovered int
	Ungrounded int
	Collisions int
}

// Ground turns model claims into locatable discoveries and discards
// everything else. It is the anti-hallucination gate: a value the model
// invented is not in the diff, so it cannot be located, so it cannot be
// reported.
//
// taken is the deduplicated detector finding set. Anything already
// covered there belongs to verdicts[], the authoritative channel, and is
// dropped here so the two arrays stay disjoint.
func Ground(diff []byte, cands []DeepCandidate, taken []detector.DedupedFinding) ([]Discovery, GroundStats) {
	stats := GroundStats{Candidates: len(cands)}
	metrics.DeepCandidatesTotal.Add(float64(len(cands)))

	seen := make(map[string]bool, len(cands))
	out := make([]Discovery, 0, len(cands))

	for _, c := range cands {
		needle, ok := groundingNeedle(c)
		if !ok {
			stats.Ungrounded++
			metrics.DeepUngroundedTotal.Inc()
			continue
		}

		file, line := locate(diff, needle)
		if file == "" {
			stats.Ungrounded++
			metrics.DeepUngroundedTotal.Inc()
			continue
		}

		// The sentinel table that auto-dismisses documented sample keys
		// in the other channel applies here too. A cold-discovered
		// AKIAIOSFODNN7EXAMPLE is the same non-secret.
		if _, isSentinel := classifySentinel(needle); isSentinel {
			continue
		}

		id := detector.FindingID(detector.Finding{File: file, Line: line, Match: needle})
		if seen[id] {
			continue
		}
		if collidesWithVerdict(taken, file, line, needle) {
			stats.Collisions++
			continue
		}
		seen[id] = true

		kind := c.Kind
		if kind != "private_key" {
			kind = "credential"
		}

		out = append(out, Discovery{
			ID:           id,
			File:         file,
			Line:         line,
			Match:        needle,
			MatchPreview: redact.Preview(needle),
			Kind:         kind,
			Confidence:   c.Confidence,
			Reason:       redact.Scrub(c.Reason, needle),
		})
		stats.Discovered++
		metrics.DeepDiscoveriesTotal.Inc()
	}

	return out, stats
}

// groundingNeedle picks the string to search the diff for, and rejects
// candidates not worth searching.
//
// Private key material gets its header line rather than the whole
// value: a PEM block spans dozens of lines, LocateInDiff searches line
// by line, and no small model reproduces a key body verbatim.
func groundingNeedle(c DeepCandidate) (string, bool) {
	v := c.Value
	if c.Kind == "private_key" {
		v = firstNonEmptyLine(v)
	}
	v = strings.TrimSpace(v)

	if len(v) < minCandidateChars {
		return "", false
	}
	if isReference(v) {
		return "", false
	}
	return v, true
}

// locate finds the value in an added line of the diff, retrying once
// with a normalized form. Models re-quote and re-punctuate what they
// copy; one normalization pass recovers those without loosening the
// gate into a fuzzy match.
func locate(diff []byte, needle string) (string, int) {
	if file, line := detector.LocateInDiff(diff, needle); file != "" {
		return file, line
	}
	if norm := normalizeCandidate(needle); norm != needle && len(norm) >= minCandidateChars {
		return detector.LocateInDiff(diff, norm)
	}
	return "", 0
}

// normalizeCandidate strips the decoration a model adds around a value
// it copied: surrounding quotes or backticks, and trailing punctuation.
func normalizeCandidate(s string) string {
	s = strings.TrimSpace(s)
	s = strings.TrimRight(s, ",;")
	if len(s) >= 2 {
		first, last := s[0], s[len(s)-1]
		if first == last && (first == '"' || first == '\'' || first == '`') {
			s = s[1 : len(s)-1]
		}
	}
	return strings.TrimSpace(s)
}

// isReference rejects values that name a secret instead of being one.
// There are no secret bytes in a reference, so reporting one can only
// be noise.
func isReference(v string) bool {
	if strings.HasPrefix(v, "$") {
		return true
	}
	if strings.Contains(v, "${") {
		return true
	}
	// A call or lookup: os.Getenv("X"), config.get(...), process.env.X
	if strings.Contains(v, "(") && strings.Contains(v, ")") {
		return true
	}
	if strings.HasPrefix(v, "process.env.") || strings.HasPrefix(v, "os.environ") {
		return true
	}
	return false
}

// collidesWithVerdict reports whether a detector finding already covers
// this value. Id equality alone is not enough: the id embeds the match,
// so a detector that matched the bare key body and a model that
// returned the whole assignment produce different ids for the same
// secret. Same file and line plus either value containing the other is
// the same finding, and verdicts[] wins.
func collidesWithVerdict(taken []detector.DedupedFinding, file string, line int, needle string) bool {
	for _, d := range taken {
		if d.File != file || d.Line != line {
			continue
		}
		if strings.Contains(d.Match, needle) || strings.Contains(needle, d.Match) {
			return true
		}
	}
	return false
}

func firstNonEmptyLine(s string) string {
	for _, line := range strings.Split(s, "\n") {
		if t := strings.TrimSpace(line); t != "" {
			return t
		}
	}
	return ""
}

type rawCandidate struct {

	Kind       string  `json:"kind"`
	Confidence float64 `json:"confidence"`

// parseDeepToolCalls reads candidates out of the tool-calling path.
// Calls for other tools are ignored: a model that also emits chatter
// should not fail the read.
func parseDeepToolCalls(calls []ToolCall) ([]DeepCandidate, error) {
	var out []DeepCandidate
	for _, c := range calls {
		if c.Function.Name != DeepToolName {
			continue
		}
		got, err := parseDeepResponse(c.Function.Arguments)
		if err != nil {
			return nil, fmt.Errorf("tool call %s: %w", DeepToolName, err)
		}
		out = append(out, got...)
	}
	return out, nil
}

// parseDeepResponse accepts the {"candidates": [...]} envelope, a bare
// top-level array, and either wrapped in a markdown code fence. An
// empty body is not an error: "nothing here" is the common answer.
func parseDeepResponse(raw string) ([]DeepCandidate, error) {
	s := strings.TrimSpace(stripCodeFence(raw))
	if s == "" {
		return nil, nil
	}

	var env deepEnvelope
	if err := json.Unmarshal([]byte(s), &env); err == nil && env.Candidates != nil {
		return convertCandidates(env.Candidates), nil
	}

	var bare []rawCandidate
	if err := json.Unmarshal([]byte(s), &bare); err == nil {
		return convertCandidates(bare), nil
	}

	// An empty object is a well-formed "nothing found".
	var probe map[string]json.RawMessage
	if err := json.Unmarshal([]byte(s), &probe); err == nil {
		return nil, nil
	}

	return nil, fmt.Errorf("unparseable deep response (%d chars): head=%q", len(s), clampStr(s, 200))
}

func convertCandidates(in []rawCandidate) []DeepCandidate {
	out := make([]DeepCandidate, 0, len(in))
	for _, c := range in {
		if strings.TrimSpace(c.Value) == "" {
			continue
		}
		out = append(out, DeepCandidate{
			Value:      c.Value,
			Kind:       c.Kind,
			Confidence: c.Confidence,
			Reason:     c.Reason,
		})
	}
	return out
}

func stripCodeFence(s string) string {
	t := strings.TrimSpace(s)
	if !strings.HasPrefix(t, "```") {
		return s
	}
	if i := strings.Index(t, "\n"); i >= 0 {
		t = t[i+1:]
	}
	if i := strings.LastIndex(t, "```"); i >= 0 {
		t = t[:i]
	}
	return t

package llm

import (
	"context"

	"github.com/juanfont/atalaia/internal/types"

// DeepResult is what one deep read produced. Truncated means coverage
// stopped at max_windows with added lines still unscanned.
type DeepResult struct {
	Candidates []DeepCandidate
	Calls      int
	Windows    int
	Truncated  bool
	Latency    time.Duration
}

// DeepReader runs the opt-in second pass: it reads a diff's added lines
// with no detector findings in the prompt and returns candidate
// credentials. It does not decide where they are. Ground does that,
// against the diff.
type DeepReader struct {
	cfg    types.LLMConfig
	client ChatCompleter
	prompt *PromptTemplate
	sem    *Semaphore
}

// NewDeepReader loads the deep templates and returns a reader. The
// semaphore is shared with the Adjudicator: both stages contend for the
// same backend, and at max_inflight 1 they take turns.
func NewDeepReader(cfg types.LLMConfig, client ChatCompleter, sem *Semaphore) (*DeepReader, error) {
	prompt, err := LoadDeepPromptTemplate(cfg)
	if err != nil {
		return nil, err
	}
	return &DeepReader{cfg: cfg, client: client, prompt: prompt, sem: sem}, nil
}

// PromptFingerprint is the deep prompt's "profile:hash", surfaced on
// /version so a stale on-disk template is visible.
func (r *DeepReader) PromptFingerprint() string { return r.prompt.Fingerprint() }

// Scan reads the diff's added lines in budget-sized windows.
//
// findings is the detector finding count for this request, used only by
// deep_scan.require_findings. Windows are scanned sequentially under a
// single semaphore acquisition, mirroring how Adjudicate batches.
func (r *DeepReader) Scan(ctx context.Context, diff []byte, findings int) (DeepResult, error) {
	if r.cfg.DeepScan.RequireFindings && findings == 0 {
		return DeepResult{}, nil
	}

	cb := r.cfg.ContextBudget
	windows, truncated := buildDeepWindows(diff, cb.InputTokens, cb.OutputTokens, r.cfg.DeepScan.MaxWindows)
	if len(windows) == 0 {
		return DeepResult{}, nil
	}

	if err := r.sem.Acquire(ctx); err != nil {
		return DeepResult{}, err
	}
	defer r.sem.Release()

	start := time.Now()
	out := DeepResult{Windows: len(windows), Truncated: truncated}

	for i, w := range windows {
		callCtx := ctx
		if r.cfg.RequestTimeout > 0 {
			var cancel func()
			callCtx, cancel = context.WithTimeout(ctx, r.cfg.RequestTimeout)
			defer cancel()
		}

		system, user, err := r.prompt.RenderDeep(DeepPromptData{Window: w})
		if err != nil {
			return DeepResult{}, fmt.Errorf("render deep window %d/%d: %w", i+1, len(windows), err)
		}

		req := ChatRequest{
			Model: r.cfg.Model,
			Messages: []Message{
				{Role: "system", Content: system},
				{Role: "user", Content: user},
			},
			MaxTokens: cb.OutputTokens,
		}
		if r.cfg.UseTools {
			req.Tools = []Tool{DeepTool()}
		}

		resp, err := r.client.Complete(callCtx, req)
		out.Calls++
		if err != nil {
			return DeepResult{}, fmt.Errorf("deep call %d/%d: %w", i+1, len(windows), err)
		}

		cands, err := r.parse(resp)
		if err != nil {
			return DeepResult{}, fmt.Errorf("parse deep response %d/%d: %w", i+1, len(windows), err)
		}
		if max := r.cfg.DeepScan.MaxCandidates; max > 0 && len(cands) > max {
			cands = cands[:max]
		}
		out.Candidates = append(out.Candidates, cands...)
	}

	out.Latency = time.Since(start)
	metrics.DeepWindows.Observe(float64(out.Windows))
	metrics.DeepLatencySeconds.Observe(out.Latency.Seconds())
	return out, nil
}

// parse prefers tool calls and falls back to message content, matching
// the adjudication path's tolerance for backends without a tool-call
// parser.
func (r *DeepReader) parse(resp ChatResponse) ([]DeepCandidate, error) {
	if len(resp.ToolCalls) > 0 {
		return parseDeepToolCalls(resp.ToolCalls)
	}
	return parseDeepResponse(resp.Content)
}

```go
// readCheckRequest handles both `text/x-diff` (raw unified diff, deep
// via ?deep=1) and `application/json` with {"diff": "...", "deep": bool}.
func readCheckRequest(r *http.Request, max int64) (diff []byte, deep bool, err error) {
	body := r.Body
	if max > 0 {
		body = http.MaxBytesReader(nil, r.Body, max)
	}
	ct := r.Header.Get("Content-Type")
	if i := strings.Index(ct, ";"); i >= 0 {
		ct = ct[:i]
	}
	ct = strings.TrimSpace(strings.ToLower(ct))

	queryDeep := r.URL.Query().Get("deep") == "1" || r.URL.Query().Get("deep") == "true"

	switch ct {
	case "application/json":
		var req apitypes.CheckRequest
		if err := json.NewDecoder(body).Decode(&req); err != nil {
			return nil, false, &httpError{"invalid JSON body: " + err.Error()}
		}
		if req.Diff == "" {
			return nil, false, &httpError{"missing diff field"}
		}
		return []byte(req.Diff), req.Deep || queryDeep, nil
	case "", "text/x-diff", "text/plain", "application/x-patch":
		b, err := io.ReadAll(body)
		if err != nil {
			return nil, false, &httpError{"reading body: " + err.Error()}
		}
		if len(b) == 0 {
			return nil, false, &httpError{"empty body"}
		}
		return b, queryDeep, nil
	default:
		return nil, false, &httpError{"unsupported content-type: " + ct}
	}
}

That gate makes fabricated line numbers impossible and fabricated secrets impossible, but it does not make the model's judgement right. Do not gate a merge on a discovery without human review.
>
> Fields: `id`, `file`, `line`, `match_preview`, `kind` (`credential` or `private_key`), `confidence`, `reason`. No `verdict`: membership is the claim. No `detections`: nothing detected it.
>
> `discoveries[]` and `verdicts[]` are disjoint. A secret both a detector and the model find is reported once, in `verdicts[]`.

Document `stats.deep_scan`, field by field, and state plainly:

> `deep_scan.error` non-empty means the deep read failed. The request still succeeded and `verdicts[]` is valid, but discovery coverage is incomplete: an empty `discoveries[]` alongside an error must not be read as clean.
>
> `deep_scan.truncated` means coverage stopped at `max_windows` with added lines unscanned.
>
> `deep_scan.ungrounded ÷ deep_scan.candidates` is the model's hallucination rate for this request.

Add `prompt_deep` to the `/version` section.

- [ ] **Step 2: Document the operational cost**

In `docs/deployment.md`, in the watcher section:

> **Deep scans need their own timeout.** A deep request is worst-case `llm.deep_scan.max_windows` sequential LLM calls, and at `max_num_seqs 1` they do not overlap. Size the watcher's HTTP client timeout from `max_windows × llm.request_timeout`, not from the sub-second latency a normal `/check` shows. The sketch above sets a timeout appropriate for the default path; raise it before setting `deep=true` or the watcher will abandon requests the server is still working.
